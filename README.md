# PostgreSQL Debugger Web 0.10.3

Локальный редактор и отладчик функций и процедур PL/pgSQL.

## Запуск

Распаковка архива и запуск приложения от обычного пользователя.

- Windows: `pg-debugger-web.exe`.
- Debian: 

```bash
tar -xzf pg-debugger-web-0.10.3-debian13-amd64.tar.gz
cd pg-debugger-web-0.10.3-debian13-amd64
./pg-debugger-web
```

Открыть адрес из терминала, если браузер не открылся сам.

## Работа с PostgreSQL

Подключитесь к локальному PostgreSQL и выберите базу, схему и функцию или процедуру. Для отладки нужны загруженный `plugin_debugger` и расширение `pldbgapi` в выбранной базе. Если нужна настройка, приложение покажет причину при подключении.

- **Отладка**: задайте аргументы, поставьте точку остановки и запустите вызов. Изменения в транзакции откатываются.
- **Редактор**: измените тело существующей функции или процедуры, проверьте и примените изменения.
- **Конструктор**: соберите заготовку из блоков. Кнопка «Применить в базе» сохраняет сгенерированное определение в PostgreSQL.

## Тестовый пример

На Debian: `./pg-debugger-web --demo` и «Открыть тестовый пример». Дебаггер сам найдёт установленный PostgreSQL с пакетом `postgresql-<версия>-pldebugger` и запустит временный сервер.
На Windows: тестовый пример через подключение к запущенному PostgreSQL.
